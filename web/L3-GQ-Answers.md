1. What command is used to create a database?
    - `CREATE DATABASE <database_name>;`. 

2. What command is used to select a database?
    - `USE <database_name>;`.

3. What command is used to display all tables?
    - `SHOW TABLES;`.

4. What SQL command is used to add records?
    - `INSERT INTO <database_name>(select columns) VALUES <row information>;`.

5. What SQL command is used to retrieve records?
    - `SELECT <parameter> from <table>;`.

6. What is the purpose of the `PRIMARY KEY` ?
    - The `PRIMARY KEY` serves as the unique identifier for each entry in a database table.

7. What is the purpose of `AUTO_INCREMENT` ?
    - `AUTO_INCREMENT` assigns to integer-type attributes a value that increments automatically for each new record.

8. What is the difference between `UPDATE` and `DELETE` ?
    - `UPDATE` changes information for a specific row; `DELETE` deletes the whole entry.
